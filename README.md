# Spanish Tenses Web Crawler

## Description
This Python program is designed for helping Latin language learners to memorize the verb conjugations.

Included Spanish tenses:
* Presente
* Pretérito perfecto simple
* Pretérito imperfecto
* Pretérito perfecto compuesto
* Pretérito pluscuamperfecto
* Futuro
* Condicional presente
* Condicional perfecto
* Subjuntivo presente
* Subjuntivo pretérito imperfecto
* Subjuntivo pretérito pluscuamperfecto

So far the list contains 1453 verbs:
* 📥 Download <code>Tiempos En Español.xlsx</code>
* 🔍 View it on Google Sheets: https://docs.google.com/spreadsheets/d/1wx-GWmak25XQuk4sqpLl_mi-D4C9FnRG/edit?usp=sharing&ouid=103784546795909129609&rtpof=true&sd=true

## Configuration
Preferred IDE: PyCharm

How to run the program:
1. Open <code>Verb List To Crawl.csv</code> and add target verbs
2. Execute <code>main.py</code>
3. Result will be output in Microsoft Excel format as <code>Output.xlsx</code>

## Utility
The result can be used in Text-to-Speech applications like: https://github.com/JusticeForSure2026/Language_Meaning_TTS
